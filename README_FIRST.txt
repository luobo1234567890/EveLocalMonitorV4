EVE Local Monitor V4
=====================

This is the Android project for EVE screen monitoring.

IMPORTANT:
- Upload the CONTENTS of this folder to the ROOT of a new GitHub repository.
- Do not upload the outer folder itself.
- The app icon is app/src/main/res/drawable/app_icon.png and is based on the supplied "给点?" image.
- GitHub Actions workflow: .github/workflows/build-apk.yml

Build:
GitHub Actions -> Build APK -> Run workflow.
